# Salesforce Feature X Incident Website

Four-screen static website for a Loom presentation.

Scenario: a fictional Salesforce Data Cloud Segmentation feature was announced as available now, but is actually in a phased rollout.

Screens:
1. Salesforce-style marketing email dashboard: 5,150 recipients and 150 clicks.
2. Public SaaS feature page with an Available Now CTA.
3. Corrected limited-rollout page with early-access modal.
4. Next-day campaign dashboard: 3,100 clicks, 1,900 interested, 500 granted access, 1,400 in pipeline.

The Salesforce UI is a presentation mockup, not an actual Salesforce screenshot.

GitHub Pages: upload `index.html` and `styles.css` to the repository root and deploy `main` / root.
